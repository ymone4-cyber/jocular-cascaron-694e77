# Importer CVAN.ONLINE dans Lovable

Cette archive contient une nouvelle direction visuelle inspirée d’un guide de musée interactif et les cinq images CVAN fournies : logo, routeur, stylo Bic, guide CVAN et ordinateur portable. Les parcours existants sont conservés comme base de migration.

## Import

1. Dans Lovable, choisis **Import project to Lovable**, puis **Upload code**.
2. Sélectionne **CVAN-ONLINE-Lovable-Atlas.zip**.
3. Après l’import, colle le contenu de **PROMPT-LOVABLE.md** dans la discussion du projet.
4. Si Lovable te demande de choisir entre la migration et l’accueil, choisis **la migration** : l’accueil interactif est déjà dans le code et le prompt lui demande de le préserver.
5. Active Lovable Cloud quand Lovable le propose et indique le courriel du compte propriétaire. Ne partage aucun mot de passe dans le chat.
6. Demande l’aperçu et la vérification des cinq images, de la navigation, de l’évaluation et de l’espace propriétaire avant publication.

Guide officiel : [Importer un projet dans Lovable](https://docs.lovable.dev/features/projects/import-project).

## À savoir

Les cinq visuels ont été découpés depuis la capture jointe, donc leur résolution est limitée. Les originaux offriront un meilleur rendu si tu les ajoutes plus tard dans public/assets avec les mêmes noms de fichiers.

Le ZIP transporte le code et ces images, pas les évaluations, les copies étudiantes ni les PDF conservés chez Netlify. Ces données devront être exportées et réimportées séparément.
